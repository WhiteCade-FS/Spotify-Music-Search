# Spotify Music Search App

## Project Overview
- <p> A full stack music searching app that uses the Spotify Web API. Users can log in and search for artists, albums, and songs and be able to click them to be brought to the Spotify Web Player to be able to listen or find what they are looking for.

### Features:
- JWT Login Flow
- Spotify artist/album/song search
- Link to Spotify Web Player
- Light/Dark mode
- Logout

### Prerequisites: 
- Node.js 18+
- Spotify Dev Account
- Spotify Account

## Getting Started
- cd into the spotify-search-app
- cd into /server
- Use "node server.js" to start the Backend
- In another window, cd into /client
- use "npm run dev" to start the Frontend

### Easiest way to use the Site
- If you use the Vercel Live Site link from below, you will see the front as well as be able to use all the features from the backend since Vercel and Heroku are linked.
